While working on this assignment, I got a much better understanding of how Django models are connected with each other. Earlier, I knew about relationships like `ForeignKey`, but working with `Order`, `Product`, and `OrderItem` made it clearer to me why we need separate models and how they work together. I also understood migrations better because I could see how changes in the models actually affect the database structure.

One thing that stood out to me was separating the actual box recommendation logic from the API view. Initially, it was easy to think of putting everything inside the view, but I understood that this would make the code harder to maintain and test. Keeping the business logic separate makes the view simpler and also allows the recommendation logic to be tested independently. This was a useful lesson for me because I can apply the same approach to other projects as well.

The part that took me the most time to understand was the box-fitting logic. At first, I thought it would just be a matter of comparing the product's length, width, and height with the box dimensions. Then I realized that a product can be rotated, and I also had to consider things like multiple quantities, total weight, and what happens when no box is suitable. Tracing through these cases helped me understand why edge cases need to be considered before deciding that an implementation is complete.

Working with AI also taught me that generating code is only one part of the process. I still had to read the code, understand the logic, test different scenarios, and check whether the implementation actually followed the assignment requirements. Sometimes an AI-generated solution can look correct at first but still make an assumption that doesn't match the requirement. So I learned that I should use AI to speed up development, but I should still verify and take responsibility for the final code.

The biggest thing I would carry forward is to think about the requirements and edge cases first, then decide how to structure the code, instead of immediately starting to write the implementation.
